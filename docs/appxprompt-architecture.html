AppxPrompt Architecture

Next.js agent that plans, builds, previews, and ships Expo SDK 54 apps

Plan, then build

  • • Planner proposes a plan. Generation starts only after confirm.
  • • chargeForBuild deducts credits in one conditional UPDATE.
  • • Each CloudHike step writes foundation, components, or one screen, then queues the next.
  • • build_events replay on the same NDJSON stream after a reconnect.

Data plane

  • • AppxPrompt Postgres via Drizzle. Prepared statements are off for PgBouncer.
  • • Generated apps call /api/apps and never hold database or storage credentials.
  • • Preview data stays in localStorage until a CloudHike backend is connected.
  • • A public home preview strips plan.backend, so visitors only see sample data.

Trust and shipping

  • • Sign-in is CloudHike Auth. The session cookie is HttpOnly for 7 days.
  • • CloudHike, GitHub, and Expo tokens are encrypted at rest.
  • • Job callbacks need a recent HMAC over the raw body.
  • • Ship a ZIP, a GitHub branch, or EAS native and web builds.
